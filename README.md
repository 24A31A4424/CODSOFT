🚢 Titanic Survival Prediction using Machine Learning

🚀 This project was developed as part of my CodSoft Data Science Internship (Task-01), where I built a classification model to predict whether a passenger survived the Titanic disaster.

📌 Project Objective

The objective of this project is to predict survival outcomes of passengers based on features like age, gender, ticket class, and more using Machine Learning techniques.

📊 Dataset Description

The dataset includes information about passengers such as:

👤 Name
🚻 Gender
🎂 Age
🎟️ Ticket Class (Pclass)
💰 Fare
👨‍👩‍👧‍👦 Family details (SibSp, Parch)
🚢 Embarked location
🎯 Survival (Target Variable: 0 = No, 1 = Yes)
⚙️ Workflow
🔹 1. Data Preprocessing
Handled missing values (Age, Embarked, etc.)
Dropped irrelevant columns (like Name, Ticket)
Encoded categorical variables (Sex, Embarked)
🔹 2. Exploratory Data Analysis (EDA)
Analyzed survival distribution
Visualized relationships between features and survival
Used graphs like count plots, heatmaps, and histograms
🔹 3. Feature Engineering
Selected important features influencing survival
Converted categorical data into numerical format
🔹 4. Model Building
Applied classification algorithms such as:
Logistic Regression
(Optional) Decision Tree / Random Forest
🔹 5. Model Evaluation
Evaluated model performance using:
Accuracy Score
Confusion Matrix
Classification Report
